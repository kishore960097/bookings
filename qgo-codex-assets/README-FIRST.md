# QGo Codex starter bundle

This bundle contains the Codex master prompt plus the original QGo vector logo and the reference animation.

## Use
1. Open the real QGo repository/workspace in Codex.
2. Copy the `reference-assets/` folder from this bundle into that workspace (or upload/place the two files somewhere inside the workspace).
3. Open `QGo-Codex-Master-Prompt.md`, copy the whole prompt, and send it to Codex.
4. Let Codex inspect the repository and implement the splash using the existing stack. The MP4 is only a reference; it should not be shipped as a production splash video.

The reference video is H.264, 1536×2048, 30 fps, 4.5 seconds, aspect ratio 3:4. The logo SVG is vector-based and has independent `qgo-q`, `qgo-g`, and `qgo-o` paths.
